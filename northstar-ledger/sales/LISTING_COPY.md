# Listing Copy

## Product title

Northstar Vibe App Preflight Pack — Ship AI-Built Apps With a Repeatable Release Check

## Short description

A local, reusable pre-launch pack for AI/vibe-coded web apps. Run a dependency-free scanner, test failure paths AI builders often skip, and turn findings into bounded coding-agent tasks with explicit acceptance criteria. No source-code upload required.

## Price

EUR 39 one-time.

## What buyers get

- Local deterministic repo scanner (Python standard library; no network calls).
- Release-readiness checklist for auth, data isolation, payments, secrets, errors, observability, backups, and rollback.
- Manual adversarial test scripts for the buyer's own application.
- Payment lifecycle matrix covering failed payments, cancellation, refunds, disputes, duplicate webhooks, and retry behavior.
- Copy-paste remediation prompts that require evidence and tests instead of blind code changes.
- Rollback/incident worksheets and a reusable launch decision record.
- Lifetime access to the purchased version; no subscription required.

## Who it is for

Founders and small teams using AI coding tools who have a working web app and want a disciplined pre-launch process before real users, real data, or real payments arrive.

## Not included

This is not a penetration test, security audit, compliance certification, or guarantee that software is safe to deploy. It is a structured self-check and remediation workflow.
