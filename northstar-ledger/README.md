# Project Northstar Ledger — Vibe App Preflight

This directory is isolated from the existing n8n workstream. Existing repository files remain untouched and are treated as read-only project history.

## Objective

Reach EUR 1,000 in payment-provider-verified gross revenue from genuine external customers while keeping owner capital injected at EUR 0 by default. The separate EUR 500 owner reserve is not business cash and remains uninjected unless a later evidence-backed request is explicitly approved.

## Model

- Free lead magnet: a local, dependency-free preflight scanner for AI/vibe-coded web apps.
- Paid product: Northstar Vibe App Preflight Pack, an offline release-readiness bundle.
- Target price: EUR 39 one-time.
- Revenue target math: 26 genuine sales x EUR 39 = EUR 1,014 qualifying gross revenue.
- Phase-1 checkout: Payhip + Stripe for automatic delivery and provider-verifiable payments.
- Fallback checkout: Lemon Squeezy.

The product is positioned as a release-readiness aid, not a penetration test, security audit, compliance certification, or guarantee.

## Rules

- Do not count owner, test, pending, refunded, fictitious, or self-purchases as revenue.
- Keep owner reserve, owner capital injected, business-generated cash, reinvestment, expenses, refunds, net revenue, and operating result separate.
- Use free tooling and organic/platform-compliant acquisition first.
- No spam, duplicate-account workarounds, moderation bypass, or fake engagement.
- Business-generated revenue is the first source for reinvestment.
- Existing n8n files and folders must not be modified by this workstream.
