PCFlows privacy notes

Last updated: 26 September 2026.

Browser quick scan

The free scanner on this site runs in your browser. The selected JSON file is parsed locally by JavaScript and is not intentionally uploaded to PCFlows by the page.

Email intake

If you email PCFlows, the information you send is processed to answer your request and, if a paid engagement is agreed, to deliver that engagement. Do not send plaintext credentials, production secrets, customer data or unnecessary personal data.

Public GitHub repository

Do not place private workflow exports, confidential logs, tokens or customer data in public GitHub issues. Public repository content can be viewed by anyone.

Payments

Paid checkout is not yet enabled on this pre-launch site. When activated, payment processing will be handled by Stripe and its own privacy terms will apply to payment data.
