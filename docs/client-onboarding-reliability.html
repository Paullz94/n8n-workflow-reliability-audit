Realistic failure patterns

Half-finished onboarding is easy to miss.

Project missing

The CRM record and welcome email succeed, but project creation fails. The customer thinks onboarding started while the delivery team has no project.

Duplicate folder/tasks

The webhook is replayed after a timeout and creates a second folder, task set or project for the same customer.

Welcome sent twice

A retry repeats the customer-facing welcome message even though the first send actually succeeded.

Required step silently skipped

A filter excludes a valid customer before a required setup action, while the scenario still finishes cleanly.

Wrong completion status

The CRM gets “Onboarding complete” before all required downstream resources exist.

Human overlap

A team member takes ownership but scheduled automated setup/follow-up continues and duplicates manual work.
