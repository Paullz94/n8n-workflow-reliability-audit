# Contra service draft

## Service name

Make.com Reliability & Data Integrity Audit

## Short positioning

A fixed-scope review of one sanitized Make.com scenario focused on duplicate effects, retries, silent skips, race conditions, error handling and recovery.

## Description

Your Make.com scenario can finish without a red error and still leave the business process in the wrong state.

PCFlows reviews one sanitized scenario blueprint for reliability and data-integrity risks such as:
- duplicate writes after retries or repeated events;
- filters or error handlers that create silent skips;
- missing recovery paths;
- parallel execution / ordering risks;
- incomplete-execution and data-loss settings;
- Commit / Rollback / Resume / Ignore behavior that changes what "success" means.

You receive:
- prioritized findings;
- evidence for each finding;
- prevent / detect / recover recommendations;
- safe verification steps;
- one asynchronous re-scan after remediation.

The review does not require production credentials.

Important:
- remove passwords, API keys, private Make webhook URLs and personal/customer data before sharing;
- static analysis cannot guarantee runtime correctness or prove the absence of defects;
- this is not a security/compliance certification.

## Requirements

Mandatory:
1. One sanitized Make.com scenario blueprint (.json).
2. PCFlows non-sensitive intake JSON.
3. Short confirmation that you are authorized to have the blueprint reviewed.

Never send:
- production credentials;
- passwords;
- API keys;
- private webhook URLs;
- unredacted customer records.

## Delivery

Initial report target: within 5 business days after complete usable input.

Included:
- one re-scan of the same scenario within 30 days of initial delivery.

## Pricing

Target commercial value: EUR 149 one-time.

At account setup, use the closest platform-supported currency/amount without silently changing the economic offer. Re-check fees/currency before publishing.

## FAQ

**Do you need access to my Make account?**
No. The pilot is designed around a sanitized exported blueprint.

**Will you fix the workflow?**
The core product is an audit, remediation order and verification plan. Implementation is not silently bundled into the fixed price.

**Is this an AI audit?**
The evidence layer is deterministic. AI-assisted interpretation may be used only on a privacy-bounded findings packet and cannot invent runtime evidence.

**What if the free scan is enough?**
PCFlows should say so rather than pushing a paid audit that does not add enough value.
