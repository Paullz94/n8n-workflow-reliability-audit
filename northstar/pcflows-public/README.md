# PCFlows

**Automation reliability and data-integrity reviews for Make.com workflows**

PCFlows helps businesses review exported Make.com scenario blueprints for reliability risks before those risks turn into duplicated actions, skipped work, inconsistent records, or difficult recovery after failures.

## Services

### Make.com Data Integrity Audit — EUR 149 pilot

The current fixed-scope pilot includes:

- review of one sanitized Make.com scenario blueprint;
- automated reliability and data-integrity analysis;
- prioritized findings for retries, idempotency, duplicate writes, concurrent execution, silent skips, error handling, recovery and observability;
- a remediation and verification checklist;
- one asynchronous re-scan after remediation.

Production credentials are not required. Customers should remove secrets, API keys, passwords and personal data before sharing a blueprint.

## Free local preflight

PCFlows is also developing a privacy-first local preflight scanner for sanitized Make.com blueprints. The core scan is designed to run locally without requiring a Make.com API token.

## Important scope limitations

PCFlows provides technical static analysis and reliability guidance. It does not provide accounting, tax, legal, security certification, or compliance certification.

Static analysis cannot guarantee runtime correctness, third-party availability, credential validity, data quality, or the absence of defects.

## Delivery

The service is delivered asynchronously as a digital report. The pilot is intended for customers who already own or are authorized to review the supplied Make.com scenario.

## Refund policy

If PCFlows cannot perform the agreed audit because the supplied material is outside the documented scope, the order will be cancelled or refunded before substantive delivery begins.

Once a customized audit report has been delivered, refunds are assessed case-by-case for material non-delivery or clear failure to provide the described service.

Support and order communication are handled asynchronously. Customers should not send production credentials, passwords, API keys or other secrets.
